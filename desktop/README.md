# 丝柯克（Skirk）桌面皮肤 · PC 版

Windows 专属悬浮皮肤。窗口**始终置顶、透明无边框**，悬浮于任何应用之上——因此 VSCode、PyCharm、Trae-IDE、WebStorm、claude-code、CodeX、kimi-code、DeepSeek Harness 等所有编辑器/终端/网页**无需任何插件即可叠加使用**。

## 使用

1. 双击 `启动-丝柯克皮肤.bat`（或右键 → 发送到 → 桌面快捷方式）。
2. 右下角出现 320px 丝柯克皮肤挂件：
   - **左键点击** → 释放元素爆发「极恶技·灭」：播放中文语音「沉于渊海。」+ 闪光/冲击波/三连斩光/冰晶碎屑/字幕动画
   - **左键拖动** → 移动位置
   - **右键** → 菜单：释放元素爆发 / 收起皮肤 / 开机自启 / 一键卸载 / 退出
3. 收起后变为“丝柯克 ✦”胶囊（同样可拖动、右键菜单含**一键卸载**）。

## 一键卸载

胶囊或皮肤上**右键 → 一键卸载 → 确认**：关闭程序、移除开机自启、延迟 2 秒后自动删除本桌面版文件夹，无任何残留。

## 开机自启

右键菜单勾选「开机自启」：写入 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`（当前用户，无需管理员）。取消勾选即移除。

## 自定义

- 换语音：把任意 mp3/wav 用 ffmpeg 转成 WAV 覆盖 `素材\语音-沉于渊海.wav`：
  `ffmpeg -i 新语音.mp3 -ar 44100 -ac 1 -c:a pcm_s16le 语音-沉于渊海.wav`
- 换立绘：替换 `素材\丝柯克-web.jpg`（建议 640px 左右竖版）。
- 改尺寸：编辑 `丝柯克皮肤.ps1` 开头的窗口/卡片尺寸（320 等数值）。
